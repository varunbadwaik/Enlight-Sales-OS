# V1.1 Product Roadmap — Automated Draft Invoice Generation System

## Overview
Post-launch enhancements and feature backlogs gathered for V1.1 development following V1.0 production stabilization.

---

## 🎯 V1.1 Feature Candidates

1. **Enhanced Gemini Extraction Accuracy**:
   - Advanced prompt tuning and multi-layout fallback models for complex non-standard vendor bill formats.
2. **Material-Specific Weight Tolerances**:
   - Configurable tolerance thresholds per material grade (e.g. HR Plate 1.0%, Structural Steel 1.5%).
3. **Advanced Operational Analytics Dashboard**:
   - Processing throughput metrics, average dispatch-to-draft turnaround time, and error rate breakdown graphs in Next.js UI.
4. **Expanded Notification Channels**:
   - WhatsApp Business API integration & Slack webhook notifications for real-time team alerts.
5. **Bulk Dispatch Processing**:
   - Batch intake and batch approval capabilities in Admin UI.
6. **Enhanced Reconciliation & Discrepancy Dispute Tools**:
   - UI comparison tool for line item rate disputes and vendor variance logs.
